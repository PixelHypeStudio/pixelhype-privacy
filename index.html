PixelHypeStudio Privacy Policy

Operated by PixelHypeStudio · Last updated: 29 August 2026

PixelHypeStudio is a digital download shop operated by an individual seller. This policy covers the PixelHypeStudio Pin Publisher, a private application that uses the Pinterest API to publish product boards and Pins to the shop owner's own Pinterest business account.

Who this application is for

The Pin Publisher is a single user, private tool. It is used only by the owner of PixelHypeStudio, acting on their own Pinterest account. It is not offered to the public, it has no sign up, and no third party ever authenticates through it.

Information the application handles

  • Pinterest OAuth tokens. When the shop owner authorizes the application through Pinterest, Pinterest returns an access token and a refresh token for the owner's own account. These are the only credentials the application holds.
  • Board and Pin data the owner creates. Product titles, descriptions, images, videos, and Etsy listing links that the owner supplies in order to publish them as Pins.
  • Pinterest API responses. Board identifiers, Pin identifiers, and error messages returned by Pinterest, used to confirm that a publish succeeded.

Information the application does not collect

  • No personal information about Pinterest users, followers, or visitors.
  • No names, email addresses, postal addresses, or phone numbers of any third party.
  • No payment or financial information.
  • No analytics, tracking pixels, advertising identifiers, or cookies.
  • No browsing history or device fingerprints.

How the information is used

The Pinterest tokens are used for one purpose only: authenticating requests to the Pinterest API in order to create boards and Pins on the owner's own account, and to read back those boards and Pins to confirm the result. The tokens are never used for any other Pinterest account and are never used to read another user's data.

Where the information is stored

Tokens are stored in a local environment file on the shop owner's own computer, outside of version control. They are not uploaded to any hosted database, not transmitted to any third party service, and not embedded in any distributed code. Product images and copy are stored locally alongside the shop's own working files.

Sharing and disclosure

No data is sold, rented, traded, or shared with anyone. The only external service the application communicates with is Pinterest itself, at api.pinterest.com, in order to perform the publish actions described above. Data may be disclosed only if required by law.

Retention and deletion

Tokens are kept only while the application is in active use and are deleted when they are no longer needed. Authorization can be withdrawn at any time from Pinterest account settings, which immediately invalidates the tokens and revokes the application's access. On revocation, any stored token is deleted.

Security

Credentials are kept out of source control, are not committed to any public repository, and are not shared with anyone. All communication with the Pinterest API is over HTTPS. If a token is ever suspected of being exposed, it is revoked in Pinterest settings and replaced.

Children

This application is not directed at children and does not knowingly handle any information relating to anyone under the age of 13.

Pinterest platform terms

Use of the Pinterest API by this application follows the Pinterest Developer Guidelines and the Pinterest Developer Terms.

Changes to this policy

If this policy changes, the updated version is published on this page and the date at the top is revised.
